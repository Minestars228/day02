# День 2: Расширешние Основ

Первое занятие. Цель — написать самый простой код и научиться его компилировать и проверять.

## Где писать код

Все файлы с кодом кладутся в папку `src/`:

- `src/task1.cpp` — Задание I
- `src/task2.cpp` — Задание II

Каждый файл — отдельная небольшая программа, у каждой своя функция `main()`.

## Что такое `#include <iostream>` и `int main()`

- `#include <iostream>` — подключает библиотеку для ввода/вывода в консоль. Без неё не заработают
  `std::cout` (вывод) и `std::cin` (ввод).
- `int main() { ... }` — точка входа программы. Когда программа запускается, выполнение начинается
  именно с `main()`. `int` в начале означает, что функция возвращает целое число — в конце пишут
  `return 0;`, это значит «программа завершилась без ошибок».

Скелет любой программы на C++:

```cpp
#include <iostream>

int main() {
    // твой код здесь
    return 0;
}
```

## Задание I. Вывести в консоль Hello World

Файл: `src/task1.cpp`

Нужно вывести в консоль строку `Hello World` (без кавычек).

```cpp
#include <iostream>

int main() {
    std::cout << "Hello World" << std::endl;
    return 0;
}
```

## Задание II. Инициализировать переменную, потом её вывести

Файл: `src/task2.cpp`

Объяви переменную любого типа (например `int`), присвой ей значение и выведи на экран. Конкретное
значение не важно — главное показать, что понимаешь, как переменную объявить, инициализировать
и вывести.

```cpp
#include <iostream>

int main() {
    int x = 10;  // инициализация переменной
    std::cout << x << std::endl;
    return 0;
}
```

## Как проверить, что всё компилируется

```bash
clang++ -std=c++17 -Wall -Wextra -Werror -o task1 src/task1.cpp
clang++ -std=c++17 -Wall -Wextra -Werror -o task2 src/task2.cpp
```

Если компилятор ничего не написал и появился исполняемый файл — всё хорошо. Флаги `-Wextra -Werror`
означают, что даже предупреждения считаются ошибками — старайся, чтобы код компилировался вообще
без предупреждений.

## Как сдать

Собери `src/` (оба файла) в zip и загрузи в локальный чекер преподавателя — он прогонит форматирование,
статический анализ и тесты, и покажет отчёт с процентом пройденных тестов.
